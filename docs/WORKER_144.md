# MCP 1.4.4
Existing queued tools wait up to 6.5 seconds for their original job and return its result when available. Status tools wait up to 8.5 seconds after the initial read. Never queue another operation to check status. Only a terminal successful result confirms execution. For sensitive requests, WordPress administrator approval still applies. New Connector 1.4.4 supports a signed automatic wake and bounded metadata-only category inventory. The existing stable tool count and OAuth scopes are unchanged. Public browser rendering and unrestricted plugin execution are not included.
