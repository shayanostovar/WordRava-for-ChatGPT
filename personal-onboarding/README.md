# Private beta installation package

This package targets the existing WordRava MCP 1.4.0 endpoint. It contains only the portable 1.0.0 manifests and public brand PNGs, not credentials or WordPress pairing secrets. It is not a public directory approval. The ChatGPT account must permit custom MCP and Plugin Creator, and the user must review/install and authorize OAuth in the same browser used for WordPress pairing. Imported MCP packages may be desktop-only in some contexts; use the supported custom MCP setup on the web if the installed package cannot expose tools. Do not promise that copying a prompt alone installs a plugin.

The archive is generated from the four files under this directory. The pinned runtime source is ca681835edff5e35aa04e3da3181400fb556e532. Runtime publishing is independent of this distribution branch.
